# HarmonyDagger-tutorial
## Installation
### Arch Linux
For SteamOS, Manjaro, etc.
1. Open a terminal (e.g., Konsole, fish, etc.)
2. Paste in:
```
python -m venv ~/Downloads/venv/
source ~/Downloads/venv/bin/activate
python -m pip install audioop-lts
python -m pip install harmonydagger
harmonydagger
```
